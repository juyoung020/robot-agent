# RecallVLA 학습 설계 — 관측·신경망·손실·자료·계산·환경 일 (2026-10-05)

목표 능력(사용자): LLM 에이전트 없이 ① 못 본 물체는 스스로 탐사해 찾고 ② 탐사 중 본 물체는 지금 안 보여도 기억에서 자리를 떠올려 곧장 가고
③ 집어서 목표(물체 또는 앱에서 누른 점)에 놓는다. 실시간으로 자라는 지도와 물체 등록 정보(이름·생김새 벡터, 상태, 불확실도)를 쓴다.
모방학습 뒤 가중치는 고정이므로 **집 배치를 외우지 않고 규칙을 배워야** 한다.

### 2.2 어텐션 가림

- 교차: 판 b 의 열쇠 = 기억 줄 [0, n_b) + 없음 열쇠 1(n_b = 0 이어도 softmax 가 정의됨). 장치 `len1 = mem_n` 으로 가림(`tk::AttP` 구간 1 + 구간 2), 텐서 코어 어텐션(hd 64, 열쇠 ≤ 257).
- 자기: 잠재 32 끼리 모두. 몸통: 인과(그대로). 기억 토큰은 지시 앞에 있으므로 지시·단계 문장·행동 전문가가 기억 토큰을 본다.
- 빈 방 항목은 열에서 빠진다(옛 빈 칸과 같은 방식). 방향 구역은 늘 8.

### 2.3 정밀 칸 고르기 (그래프 안, 기울기·그래프 잡기 안 깸)

판마다 워프 하나(`mem_sel_k`), 순서대로 채워 합 min(8, n):
1. 들고 있는 물체 → 2. 목표 칸 물체(앱·에이전트 id, 감추기 판에선 없음) → 3. 에이전트 힌트(299 = 1) → 4. (학습 일정) 정답 끼워 넣기 `rec_force` →
5. q_pick·q_place 로짓 상위 2 씩 번갈아(**"기억에 없음" 로짓보다 클 때만** — 없음이 이기면 목표에 칸을 쓰지 않음, D3) → 6. 가까운 순(경로 거리).
같은 값은 앞 줄 먼저(결정적). 고른 줄을 그대로 옮기고 299–301 표시를 쓴다.

- **기울기**: 고르기는 이산(top-k 와 같음)이라 고르기 자체엔 기울기가 없다. 기울기는 (a) 고른 칸의 φ(같은 φ 라 기억 쪽과 함께 배움) (b) 검색 InfoNCE(3절) (c) 몸통 → 기억 토큰으로 흐른다.
- **그래프 잡기**: 출력 크기 고정(8 칸, 빈 칸 −1·0 줄), 호스트 동기 없음. 정밀 칸 토큰 수(= min(8, n))는 n 만으로 정해지므로 호스트가 열(src)을 미리 짠다. V6(그래프 == 즉시) 0 다름.
- 학습 때 정답 끼워 넣기 비율 p 는 데이터 쪽 일정(처음 1.0 → 0.2 (추정)) — 검색이 아직 엉터리일 때도 정밀 칸이 쓸모 있게.

### 2.4 KI 와 기울기 길

- KI 켬(기본): 전문가 → 몸통 prefix K·V 기울기를 끊는다(그대로). 그래서 flow 손실은 기억 인코더·φ·몸통에 안 간다.
- 기억 인코더·φ 는 **단계 문장 CE(몸통 경유) + 검색 InfoNCE + 있음 BCE** 로 배운다. 검색 손실이 KI 와 무관한 직접 신호다.
- KI 끔 판도 같은 코드(V5 `--mem --ki0` 통과).

### 2.5 이산 행동 토큰 (선택, 설계만)

MAPVLA_SPEC 4.2 그대로: 차원마다 256 칸 → 어휘 끝 256 개 재사용, 단계 문장 뒤에 16 × 8 토큰, λ_tok 0.5 (추정). KI 켬에서 몸통이 행동을 아는 유일한 길. 구현 안 함(다음 일).

## 3. 손실 (구현: 1·2·3·4·5. 6 은 선택)

L = λ_txt·CE(단계 문장) + λ_fm·flow + λ_rec·InfoNCE(물체) + λ_ex·BCE(있음) [+ λ_tok·CE(이산 행동)]

| 손실 | 식 | 무게 (시작, 추정) |
|---|---|---|
| 1 단계 문장 CE | 다음 토큰 CE, 어휘 전체 | λ_txt 1 |
| 2 flow matching | 가림 있는 행동 차원만, τ ~ U(0,1) | λ_fm 1 |
| 3 물체 InfoNCE | 역할 r ∈ {집기, 놓기}: 로짓 s_r,j = cs·q_r·k_j, j = 없음 열쇠 또는 기억 줄 0..n−1. q_r = 끝 블록 교차 어텐션의 잠재 r 질의, k = 같은 블록 열쇠, cs = 1/(√hd·머리 수) — **끝 블록 머리 평균 주목 로짓 그 자체**. softmax CE, 정답 없음 = 없음 열쇠. 정답이 없음인 표본 무게 `rec_null_w`(1, 없음이 쏠리면 0.1 — DETR ∅ 0.1) | λ_rec 0.5 |
| 4 있음 BCE | 기억 토큰 r 에 선형 → σ = P(목표가 기억에 있음). 정답 = 줄 번호 ≥ 0 이면 1, 없음이면 0 | λ_ex 0.2 |
| 5 라벨 없음 | 정답 −2(국면상 그 역할 목표가 없음, 예: 점 목표의 집을 것) → 3·4 둘 다 0 | — |
| 6 이산 행동 CE | 2.5 | λ_tok 0.5 (선택) |

**"기억에 없음" 이 실제로 골리게** (D6, 근거):
1. 같은 softmax 안의 null 칸: SQuAD 2.0 의 답 없음을 BERT [CLS] 로 고르는 방식(Rajpurkar 외 2018, arXiv 1806.03822; Devlin 외 2019), DETR 의 ∅ 부류(Carion 외 2020, arXiv 2005.12872), Visual Sentinel(Lu 외, CVPR 2017, arXiv 1612.01887) — 3 번 손실.
2. 따로 "있음" 확률 머리: GRES / gRefCOCO(Liu 외, CVPR 2023, arXiv 2306.00968) — 목표 없음 라벨을 명시. **두 머리가 같은 말을 할 때만 확신 있게 행동**(null 이 지거나 σ ≥ 문턱이면 찾음, 둘이 엇갈리면 "가서 확인").
3. 추론 여유 문턱: m = s_null − max_j s_j 가 τ 보다 크면 없음. τ 는 **검증 집**(학습 안 쓴 집)에서 헛집음 대 놓침 곡선으로 고르고, 헛집음이 더 나쁘므로 보수적으로(**헛집음 ≤ 2 %** 에서 놓침 최소 — 사용자 결정 10-05, 조정 가능 값 `null_fp_target = 0.02`).
4. 다가간 뒤 확인(Read + Verify, Hu 외 AAAI 2019, arXiv 1808.05759 의 꼴): 정밀 칸에 든 뒤 손목 카메라 생김새로 다시 점수 → 다르면 다음 추론에서 그 줄의 검색이 없음 쪽으로 뒤집히고 탐사를 잇는다. 학습: 확인 실패 판(비슷한 가짜에 다가갔다가 돌아서는 교사 궤적)을 섞음(4.3).
5. 자료: 목표 없음 판 20–30 % (가정) + 어려운 근접 오답(못 본 목표, 비슷한 가짜만, 속성 불일치 — "빨간 컵" 인데 파란 컵만). 없음 쏠림이면 `rec_null_w` 0.1.

### 3.1 시뮬 라벨 만들기

| 라벨 | 어디서 | 규칙 |

## 4. 자료 흐름

### 4.1 교사 → 학생

```
RL 교사(PPO, 같은 자라는 지도, 특권 = 지도에 이미 있는 물체의 정확한 물리만, 방 항목·방향 구역도 봄)
   │  못 본 목표 = 교사도 탐사로 찾음(안 보고 곧장 가기 금지 — POLICY 4.2)
   ├─ 대본 탐사 교사(둘 다 계획 — 사용자 결정 10-05): 방향 구역 중 "안 본 넓이 / 경로 거리" 최대로 가는 덮기 + 덜 살펴본 가구 들르기.
   │   PPO 교사의 판 A 탐사 성공률이 정체되면(기준 (추정): 1M env-step 동안 개선 < 2 %p) 이 교사의 판으로 BC 시작 자료·PPO 앞 모방을 만든다
   ▼
BC 기록(표본마다: 영상 렌더 열쇠, 지도 토큰, 기억 표 스냅숏 열쇠, 라벨) → DAgger(학생 행동으로 굴리고 교사가 다시 라벨)
   ▼
RecallVLA S1(지도·기억 질의 짧은 답 + 단계 문장, 영상 얼림 가능) → S2(전부, 판 A–D 섞음) → S3(실제 LIMO 시연 미세조정 — 필수, MAPVLA_SPEC 4.8)
```

- **교사가 탐사를 배우는 법**: PPO 보상 = 과제 보상 + 새로 본 칸 보상(작게, 판 A·C 에서만) (추정). 교사 관측에 방향 구역 8·방 항목이 있어 학생과 같은 정보로 탐사 규칙을 배운다.
- 기록은 디스크 없이(GPU 시뮬이 학습 때 다시 만듦, BC G5 방식). 기억 표는 환경 상태에서 매 스텝 다시 만들 수 있어 기록하지 않는다(재생 = 같은 열쇠 → 같은 비트, W1 검증).

### 4.2 단계 문장 표 (영·한, 국면 → 문장)

| 국면 | 영어 틀 (예) | 조건 |
|---|---|---|
| 탐사(목표 없음) | `the {obj} is not in the map; explore to the {left/right/front/back}` | 1 단계 없음 + 교사의 다음 1 s 이동 방향(45° 칸 → 말 4 개로 묶음) |
| 가구 살펴보기 | `check the {furniture}` | 교사가 가구 쪽으로 다가가는 중이고 정답이 아직 기억에 없음 |
| 기억에서 가기 | `the {obj} is in the {room}; go there` / `go to the {obj}` | 정답 줄 있음, 보이지 않음 |
| 다가가기·집기·놓기 | `pick up the {obj} from the {src}`, `put the {obj} on/in the {dst}`, `put it here` | MAPVLA_SPEC 4.1 |
| 확인 실패 | `that is not the {obj}; keep looking` | 4.3 판 E |
| 끝(없음) | `I could not find the {obj}` | 판 A 끝까지 못 찾음(교사가 다 덮음) — 끝 신호 |

### 4.3 판 종류와 비율 (B2–B5 위, 비율 (추정) — 학습 중 잼)

| 판 | 내용 | 비율 |
|---|---|---|
| 보임·가까움 | 지금 B2–B5 | 25 % |
| A 빈 지도 찾기 | C2 에서 시작, 목표 종류 아직 없음 | 20 % |
| B 미뤄 떠올리기 | 1 부 탐사·다른 일 N 스텝 → 2 부 "1 부에서 본 것" 가져오기, 목표는 화면 밖 | 20 % |
| C 낡은 기억 | B + 1·2 부 사이 목표 옮김 | 10 % |
| D 헷갈리는 등록 | 같은 종류 여럿·속성 지시·이름 일부러 틀림 | 10 % |
| **N 목표 없음** | 목표가 집에 없음(비슷한 가짜만·속성 불일치 포함) → 다 덮고 끝 | 10 % (A 의 일부와 합쳐 없음 정답 20–30 %) |
| E 확인 실패 | 가짜에 다가가 손목 카메라로 확인 → 돌아섬 | 5 % |

에이전트 힌트: 판의 30 % 에 힌트(그중 20 % 틀린 힌트), 나머지 지움 (추정). 목표 칸 감추기 0.5(그대로).

### 4.4 외우지 않게

- **집 다양성**: BEHAVIOR 학습 집 4 채만으로는 배치를 외운다 → **절차 생성 집**(ProcTHOR-10K, Apache-2.0)을 주로, BEHAVIOR 는 섞음(30 %, 추정). 판마다 집 반전·90° 회전, 물체 배치·시작 자리 무작위, 처음 지도 C0/C1/C2 섞음.
- 기억 줄 순서 섞기(집합), 이름 흔들기·지우기·틀린 이름, 방 종류 확률 흐리기, 방향 구역은 로봇 기준이라 집 방향과 무관.
- **평가**: 안 쓴 집(ProcTHOR 검증 묶음 + BEHAVIOR 평가 3 채)에서 판 종류별 성공률·SPL, B 의 "곧장 갔나"(경로/최단), N 의 헛집음·끝 정확도, 검색 R@1·없음 정확도. **학습 집 대 안 쓴 집 차이**가 외운 정도. 기억 끔(옛 16 칸) 대비.
