# 상태·입력 사양 — RL 교사와 RecallVLA 학생 (전체 목록)

이 문서 하나로 "정책이 무엇을 보고 무엇을 내는가"를 빠짐없이 알 수 있게 한다. 값 이름·자리·단위·정규화는 코드와 같다.
코드 원천: `training/RL/env/include/env.h`(몸·관측), `training/RL/map/include/map_tok.h`(지도 토큰), `training/RL/observation/include/obs.h`(정규화·교사 입력 줄), `training/RL/network/include/net.h`(교사 신경망 입력), `training/vla/include/model.h`(학생). 설계 배경: [VLA_INPUT](VLA_INPUT.md), [POLICY](POLICY.md), [TRAINING_DESIGN](TRAINING_DESIGN.md), 기억 인코더 설명 [MEMORY_ENCODER](MEMORY_ENCODER.md).

공통 원칙
- 모든 위치는 **상대값**: 로봇(`base_link`, x 앞·y 왼쪽·z 위) 기준 또는 손끝(`omx_end_effector_link`) 기준. 로봇 자세는 SLAM 으로 믿는 자세(정답 아님).
- 지도 좌표·물체 id·방 id·클래스 번호·지도 크기는 어디에도 넣지 않는다(어느 집에서든 같은 뜻).
- 지도는 정답(GT)이 아니라 빈 지도에서 SLAM 으로 자라는 지도.

## 8. 학생 기억 인코더 — 질의(잠재) 32 개가 무엇인가

| 질의 | 역할 | 어떻게 정해지나 |
|---|---|---|
| 0 = q_pick | 집을 물체 찾기 | 검색 손실(InfoNCE)로 정답 물체에 1 등 점수를 주게 학습, 못 봤으면 "기억에 없음" 이 1 등 |
| 1 = q_place | 놓을 곳 찾기 | 같음 |
| 2–31 | 자유 요약 30 개 | 따로 뜻을 정하지 않음 — 단계 문장·행동을 잘 내는 데 필요한 요약으로 학습(장애물·같은 방 물건 등은 사람이 붙인 해석일 뿐) |

모든 질의에 지시 벡터(128 + 편향 → 136 → 1024 선형)를 더해 지금 과제에 맞춘다. 블록 2 개 × [교차 어텐션(질의 32 → 기억 줄 N + "기억에 없음" 1, 머리 16 × 64) → 자기 어텐션(질의끼리) → SwiGLU 4096], pre-RMSNorm. 출력 = 기억 토큰 32 개. 정밀 칸 8: 들고 있는 것 → 목표 칸 물체 → 힌트 → (학습) 정답 끼워 넣기 → q_pick·q_place 점수 상위(기억에 없음보다 클 때) → 가까운 순. 자세히: [MEMORY_ENCODER](MEMORY_ENCODER.md) 8절.

기억 상한 256(교사·학생·실제 같음). 넘으면 인코더 앞에서 목표·들고 있는 것 → 같은 방 → 가까운 순 → 최근 본 순으로 고른다.
