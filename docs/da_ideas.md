## 아이디어 (기대 효과 큰 순)

### 1. 애매한 쌍은 합친 마스크로 다시 담아 검정 — 중복

- 병합 로지스틱에서 cos 무게가 가장 크다(`wm[4]` 8.8). 그런데 **같은 물체의 다른 부분**(소파 등받이 ↔ 쿠션, 컵 윗면 ↔ 옆면)은 SigLIP 벡터가 서로 다르다.
- 조각뿐인 물체의 "통째 다시 담기"는 자기 구름(= 그 조각)만 다시 찍으므로 여전히 일부 모습이다 → cos 가 계속 낮아 안 합쳐짐.
- 안: P 가 애매(예 0.3–0.7)하고 접촉이 높은 쌍은 **두 구름 합집합을 투영한 마스크**로 다시 담기를 요청. 합친 모습의 κ·이름 사후가 각 조각보다 확신 있으면 합침(새 관측으로 가설 검정).
- 자리: `sm_reencode_requests` 경로 그대로, 요청 수 한도(`reenc_max`) 안에서.

### 2. 접촉 판정은 몸 빼기 전 점으로 — 중복(집기 대상)

- `known_bugs.md` O2: `body_r`(0.22 m) 안 점을 구름에서 빼서 리모 바로 앞 작은 물체(컵)가 윗면·옆면 두 조각으로 남음.
- 안: 접촉 칸 색인은 몸 빼기 전 점으로 만들고, 빼기는 구름 저장에만.

### 3. 불확실성을 쓰는 게이트·거리 — 중복·잘못 합침

- 게이트는 상자 틈 0.3 m 고정이고, 칼만 분산 `ap->P` 는 계산만 하고 연관에 안 쓴다.
- 안: 중심 거리 특징을 마하라노비스 `d² = Σ Δ_k² / (P_k + R_k)`(R = `kalman_R`) 로 바꾸거나 특징 하나로 더해 다시 맞춤. 멀리서 본(깊이 잡음 큰) 것과 가까이 본 것을 같은 잣대로.

### 4. 같은 종류 이웃 막기 — 잘못 합침

- 의자 ↔ 의자, 식탁 ↔ 의자: cos 가 원래 높고 마스크가 섞이면 접촉도 생김. `name_veto`·`bridge_drop` 은 효과 없어 꺼 둠.
- 안 A(빈 공간): 두 물체 사이에 점유 격자로 **비었다고 본 칸**이 있으면 같은 것 아님. 2D 격자가 이미 있음.
- 안 B(`bridge_drop` 고침): 두 물체에 걸친 조각을 버리는 대신 둘 다 '보임' 만 하고 **구름에는 안 넣음**. 지금은 붙이면 다음 병합에서 둘을 합치고, 버리면 중복이 늘었다.

### 5. 로지스틱 일반화 확인

- 가중치를 radio r3 정답 쌍으로 맞추고 r3 로 채점 중. 다른 시퀀스로 맞추고 r3 로 채점해 과적합인지 본다.

## 하지 않을 것

- 헝가리안 같은 1:1 배정: 조각 여럿이 한 물체에 붙어야 해서 맞지 않음. 배정 방법보다 특징·검정을 보강한다.
