# 관측 (G3)

`include/obs.h` 의 `obsv::assemble` 하나가 G1 관측 80(`env.h`)과 G2 지도 토큰 `MapTok`(1,280 B, `map_tok.h`)을 신경망 입력으로 바꾼다. CPU·GPU 같은 소스(비트 동일).
롤아웃(정책 앞 계산)과 갱신(미니배치 모으기)이 같은 함수를 쓰므로 같은 (스텝, 판)이면 입력 비트가 같다. 그래서 첫 미니배치의 PPO 비율이 정확히 1 이다.

| 입력 | 자리 | 정규화 (가정) |
|---|---|---|
| G1 관측 80 (몸 상태 56 + 벽 광선 16 + 목표 칸 8) | X0[128, 208) | 그대로, ±10 자름 |
| 지도 벽 56 (`MapTok::wall`) | X0[208, 264) | 그대로(이미 /4 m) |
| 방 10 | X0[264, 274) | 문 x·y·거리만 /4 |
| 완성도 4 | X0[274, 278) | 그대로 |
| 물체 칸 16 × (숫자 33 + 이름 원-핫 7 + 생김새 원-핫 7 + 1) | 칸 줄 | 마지막 본 뒤 시간 /10, 본 횟수 /20, 나머지 그대로, ±10 자름 |

- 롤아웃 버퍼에는 정책이 실제로 본 지도 토큰을 스텝마다 저장한다(5.3). `TokenRecorder(N, T+1)` 의 줄 t = 스텝 t 에 본 토큰. 바퀴가 끝나면 마지막 줄을 0 줄로 옮긴다.
- 교사 특권(5.4): G1 관측의 목표 칸 8(컵의 몸 기준 xy·거리·에임·보임·겉면 거리)은 참값이다. 지도 토큰(물체 칸·벽·방)은 G2 의 자라는 지도(slam 오차·검출 실수 포함)다.
- `use_map = 0` 이면 지도 입력을 모두 0 으로 한다(빈 칸, 관측 80 만).
