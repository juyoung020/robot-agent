# 단계별 보상 (G3)

- **기본 보상은 G1 환경이 낸다**(`../env/include/env.h` `step_core`, [CURRICULUM_APPROACH.md](../../../docs/map_vla/CURRICULUM_APPROACH.md) 2절: 다가가기 ×5, 에임 ×2, 보임 +1, 성공 +10 + 5·cos 에임, 충돌 −10, 가까움·덜컥임·시간). 여기서 바꾸지 않는다.
- `include/shaping.h`: 학습기가 GAE 에서 더하는 **퍼텐셜 기반 모양 잡기** `coef · (γ·Φ(s') − Φ(s))`. 최적 정책을 바꾸지 않는 꼴이다(Ng et al. 1999). 기록하는 반환값은 G1 보상만이다.
  - Φ = −near·max(0, 0.4 − 겉면) − aim·max(0, 에임 − 10°)[겉면 < 1.5 m] + 성공 영역(겉면 0.4–0.8 m·에임 ≤ 10°·보임)이면 zone − v·max(0, |v| − 0.05) − w·max(0, |w| − 5°/s).
  - 무게 기본값 near 8, aim 1, zone 1, v 4, w 2 **(가정)**. 진짜 끝(성공·충돌)은 Φ(s') = 0. 에피소드 첫 스텝은 더하지 않는다. G1 은 끝난 스텝의 관측을 돌려주므로 새 판 첫 스텝의 관측이 지난 판 끝 값이기 때문이다.
- 왜 넣었나(잰 것, `../ppo/README.md`): G1 보상만으로는 A0 에서 6.2e8 환경 스텝 동안 성공이 0 번이었다. 정책은 성공 영역을 지나 충돌 직전까지 붙어 섰다. 다가가기 보상이 직선 거리에 ×5 라 영역(겉면 0.4–0.8 m)보다 더 붙는 쪽이 늘 이득이고, 1 s 멈춤 성공(+15)은 한 번도 나오지 않았다. 모양 잡기를 켜면 같은 설정에서 1.6e8 스텝에 A0 성공률 0.90 이다.
- CURRICULUM 2절은 다가가기에 **경로 거리**를 쓰라고 한다. A0/A1 은 빈 방이라 직선 거리 = 경로 거리다. **A2** 는 G1 환경이 경로 거리를 낸다(`../env/README.md` A2: 부풀린 가구 둘레 보임 그래프 최단 경로, 참 장면 기준 — 문서는 "정책이 아는 지도" 기준이라 C1·C2 에서는 다름). 모양 잡기 Φ 는 그대로(겉면·에임·보임은 직선 값, 목표 근처에서만 켜짐).

## G4
- **탐색 보상은 넣지 않았다**: 목표를 지도에서만 받게 한 뒤(`../observation/README.md` goal_mode 1)에도 빈 지도 성공률이 탐색 보상 없이 0.98 을 넘었다(`../ppo/README.md` G4). G1 보상(다가가기·에임·보임)은 참 컵 기준이라, 정책이 컵을 못 보는 동안에도 보상은 참 목표로 계산된다(관측이 아닌 보상의 비대칭 — 가정: 이 비대칭이 탐색을 돕는다고 보지만 따로 재지 않음).
- **충돌 추가 벌** `ShapeP::coll`(설정 `shaping.coll`): 충돌로 끝난 스텝에 더한다(G1 −10 에 더함, 기록 반환값엔 안 들어감). 퍼텐셜 꼴이 **아니다** — 최적 정책을 일부러 바꾼다. 까닭(잰 것): G1 보상에서는 최대 속도·최대 회전 호로 돌다 벽을 긋는 A1 충돌 3 % 가 남았고, −20 을 더하자(합 −30) 결정적 성공 0.9702 → 0.9994, 충돌 0.0298 → 0.0006 이었다(`../ppo/README.md` G4). 값 −20 은 (가정). 기본 0(끔).
- 모양 잡기 Φ 는 그대로 참값(G1 관측)을 쓴다. 목표를 아느냐로 Φ 를 가리면 목표를 찾는 순간 Φ 가 뛰어(가까이·빗나간 에임이면 음수) 찾기를 벌하게 되므로 가리지 않았다.
