# 단계별 보상 (G3)

- **기본 보상은 G1 환경이 낸다**(`../env/include/env.h` `step_core`, [CURRICULUM_APPROACH.md](../../../docs/map_vla/CURRICULUM_APPROACH.md) 2절: 다가가기 ×5, 에임 ×2, 보임 +1, 성공 +10 + 5·cos 에임, 충돌 −10, 가까움·덜컥임·시간). 여기서 바꾸지 않는다.
- `include/shaping.h`: 학습기가 GAE 에서 더하는 **퍼텐셜 기반 모양 잡기** `coef · (γ·Φ(s') − Φ(s))`. 최적 정책을 바꾸지 않는 꼴이다(Ng et al. 1999). 기록하는 반환값은 G1 보상만이다.
  - Φ = −near·max(0, 0.4 − 겉면) − aim·max(0, 에임 − 10°)[겉면 < 1.5 m] + 성공 영역(겉면 0.4–0.8 m·에임 ≤ 10°·보임)이면 zone − v·max(0, |v| − 0.05) − w·max(0, |w| − 5°/s).
  - 무게 기본값 near 8, aim 1, zone 1, v 4, w 2 **(가정)**. 진짜 끝(성공·충돌)은 Φ(s') = 0. 에피소드 첫 스텝은 더하지 않는다. G1 은 끝난 스텝의 관측을 돌려주므로 새 판 첫 스텝의 관측이 지난 판 끝 값이기 때문이다.
- 왜 넣었나(잰 것, `../ppo/README.md`): G1 보상만으로는 A0 에서 6.2e8 환경 스텝 동안 성공이 0 번이었다. 정책은 성공 영역을 지나 충돌 직전까지 붙어 섰다. 다가가기 보상이 직선 거리에 ×5 라 영역(겉면 0.4–0.8 m)보다 더 붙는 쪽이 늘 이득이고, 1 s 멈춤 성공(+15)은 한 번도 나오지 않았다. 모양 잡기를 켜면 같은 설정에서 1.6e8 스텝에 A0 성공률 0.90 이다.
- 다음: CURRICULUM 2절은 다가가기에 **경로 거리**를 쓰라고 한다. 지금 G1 은 빈 방이라 직선 거리다. 장애물이 생기는 A2 부터는 G2 격자 위 경로 거리가 필요하다.
