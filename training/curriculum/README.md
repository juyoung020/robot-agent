# 강화학습 커리큘럼 — 교사 시연 → RecallVLA 모방학습 (2026-10-06 결정)

큰 그림: **다양한 RL 교사**를 만들어 **다양한 스폰·맵·시나리오**에서 모범 답안(시연)을 얻고, RecallVLA(학생)가 그 시연을 **모방학습**(BC → DAgger)한다. 지도는 정답(GT)이 아니라 빈 지도에서 SLAM 으로 자라는 지도다.

| 단계 | 배우는 것 | 교사가 받는 목표 | 지금 학습 환경 단계 | 끝 판정 |
|---|---|---|---|---|
| 1 | 지도 최대한 많이 쌓기 | 없음(탐사) | **새로 만들어야 함** — 새로 본 칸 = 보상(GPU 지도가 방마다 이미 셈) | 정해진 시간 안 덮은 비율 |
| 2 | 목표 지점 주면 가기 | 지도 위 점 | B1 점으로 가기(`p_goto`) | 점 0.3 m 안에서 멈춤 |
| 3 | 물체 찾기 | 물체 종류 | B2 찾기 | 목표 물체 지도 확정 + 카메라에 보임 |
| 4 | 물체 잡기 | 물체 | B4 집기(잡는 자세에서) | 들어 올림 0.05 m · 0.5 s |
| 5 | 물체 찾아서 잡기 | 물체 종류 | B2 찾기 + B3 다가가기 + B4 집기(놓기 없음, 환경에 더해야 함) | 4 와 같음 |

## 누가 배우나
- **교사 = RL 정책**(`training/RL`, PPO): 시뮬 상태를 아는 정책이 단계마다 과제를 먼저 익힌다. 교사는 목표 칸(지점 좌표 또는 물체)과 **지시문 임베딩**(얼린 표의 128 차원 행 — 학생 글 토큰과 같은 벡터, X0_INSTR)을 관측으로 받는다.
- **학생 = RecallVLA**(`training/BC`·`training/vla`): 교사들의 시연을 모방학습해, 카메라·물체 기억(기억 인코더)·지시문만으로 같은 과제를 한다.

## 입력·상태 — RecallVLA 와 RL 교사 통일 (VLA_INPUT·POLICY 결정)

**RecallVLA(학생) 입력**

| 입력 | 내용 |
|---|---|
| RGB 그림 2 장 | ① 리모 몸통 카메라 ② OMX 손목 카메라 — 같은 SigLIP 2. **위에서 본 지도 그림은 뺀다(2026-10-06 결정, 아래)** |
| 몸 상태 56 | 팔 · 몸통 · 목표 토큰 3 |
| 목표 칸 2 | 집을 것 · 놓을 곳 = 물체 또는 지도 위 점, 로봇 기준 상대 좌표 |
| 물체 기억 | 전체(≤ 256) → 기억 요약 인코더 → 기억 토큰 32 + 정밀 칸 8 |
| 방 · 탐사 경계 · 주변 공간 | 방 항목 ≤ 8, 탐사 경계 후보 ≤ 8, 벽 · 방 토큰 |
| 지시 문장 | LLM 이 준 지금 단계 한 줄 |

- 깊이는 그림으로 넣지 않는다(지도·지도 그림을 만드는 데만). 지난 프레임을 쌓지 않는다 — 긴 기억은 물체 기억 토큰과 지도 그림.
- 모든 위치는 로봇·손끝 기준 상대 좌표, 지도마다 다른 값(지도 좌표·방 id·물체 id·클래스 번호)은 넣지 않는다.

**RL 교사와 통일(2026-10-06)**
- 교사 행동 망은 학생과 **같은 관측**(빈 지도에서 자라는 지도, 같은 관측 코드). **특권 정보**(정답 자세·질량·잡을 자리 …)는 **가치 망에만**(비대칭 행동자–가치).
- 교사도 안 본 물체는 모른다 — 학생이 흉내 낼 수 있는 행동만 나오게.
- 교사는 영상을 직접 보지 않는다: 같은 물체 칸·격자·숫자 관측을 쓴다. 지시문은 학생과 같은 임베딩 벡터로 받는다(`net.h X0_INSTR`).

**결정(2026-10-06): 지도 그림은 주지 않는다 — 카메라 2 대만.** 위에서 본 지도 **그림**(학생 셋째 그림)만 뺀다 — 지도를 통째로 주면 MDP 에 어긋난다(사용자 판단). **토큰은 그대로 둔다**: 16 × 16 격자(장애물·안 본 칸 비율, 교사 X0 의 tv)·벽·방·탐사 경계·물체 칸(로봇 기준 상대 좌표·거리). 학생도 그림 대신 같은 격자 토큰을 받아 교사와 입력이 같다. 코드에서 바꿀 곳: `training/BC`(셋째 그림 → 격자 토큰), `training/vla`(카메라 3 → 2, 격자 토큰), `og_replay_lib.py`·`sm_tok.h`(그림 만들기). 교사 쪽(X0 의 격자)은 그대로.
- 정의: [VLA_INPUT](../../docs/map_vla/VLA_INPUT.md), [POLICY](../../docs/map_vla/POLICY.md) 4.2, [MAPVLA_SPEC](../../docs/map_vla/MAPVLA_SPEC.md).

**학생 RecallVLA**
- 그림: **카메라 2 장**(몸통·손목) — 지도 그림은 뺌(10-06)
- 몸 상태 56 → 토큰 3(팔·몸통·목표), 목표 칸 2 × 16
- 물체 기억 전체(≤ 256) → 기억 토큰 32 + 정밀 칸 8
- 토큰: 격자 2 × 16 × 16(그림 대신 — 교사와 같은 값)·벽·방 항목·탐사 경계 후보
- 지시 문장(글 토큰)

**물체 칸 289(교사 칸·학생 기억 인코더 입력 같음, VLA_INPUT 3절)** = 숫자 33 + 이름 뜻 128 + 생김새 128. 숫자 33 에 **물체 ↔ 나 상대 위치·거리**가 들어간다: 위치 xyz(로봇 기준) 3·(손끝 기준) 3, 거리·방향 2, 손끝 ↔ 중심·겉면 거리 2, 팔이 닿는지 1, 위치 불확실도 1 — 그리고 크기 3, 옮겨진 양 3, 속도 3, 상태 4, 마지막 본 뒤 시간 1, 믿을 만한 정도 2, 출처 1, 같은 방 1, 목표인지 1, 이름 확신도 2. 지도 좌표·물체 id 는 없음.

**교사·학생 차이**: 카메라(학생만), 물체 기억 범위(교사 칸 16 / 학생 전체를 요약), 지시문 형태(교사 임베딩 벡터 / 학생 글 토큰). 나머지 상태·토큰은 같은 값.

## 교사 기억 인코더 — 학생과 같은 틀 (결정 2026-10-06, 구현 할 일)

쉬운 설명(처음 보는 사람용): [docs/map_vla/MEMORY_ENCODER.md](../../docs/map_vla/MEMORY_ENCODER.md).

지금 교사는 GPU 지도의 물체 기억(판마다 ≤ 256, `map.h NOBJ`) 중 16 칸만 본다. 학생과 같은 기억을 보도록 교사 망에도 기억 요약 인코더를 넣는다(MAPVLA_SPEC 2.8 과 같은 틀, 폭만 작게).

| 부분 | 학생(RecallVLA, 2.8) | 교사(PPO) |
|---|---|---|
| 입력 | 기억 물체 전부 N ≤ 256(칸 형식 304) + 지시 벡터 128 | 같음(빈 칸은 빼고 압축) |
| 물체 인코더 φ | 304 → 1024 → 1024 | 지금 칸 MLP 그대로 304 → 64 → 64(같은 φ 를 모든 물체·정밀 칸에) |
| 잠재 질의 | 32(검색 질의 q_pick·q_place 2 + 자유 30), 지시 벡터를 더함 | 같음, 폭 64 |
| 블록 | 2 × (교차 어텐션 → 자기 어텐션 → MLP) | 같음, 폭 64·머리 4 |
| null 열쇠 | q_pick·q_place 에 "기억에 없음" | 같음 |
| 정밀 칸 | 8(들고 있는 것·목표·검색 점수 상위·가까운 순) → φ | 같음 |
| 몸통으로 | 기억 토큰 32 + 정밀 칸 8 | 기억 32 × 64 + 정밀 8 × 64 를 펴서 X0 의 물체 집합 128 자리에 |

**기억 상한(결정 2026-10-06)**: 물체는 **최대 256 개**(교사·학생·실제 로봇 같은 규칙 — 학습과 실행이 같게). 넘으면 정해진 규칙으로 정렬해 앞에서 256 개(인코더 앞 거름망이라 학습된 점수는 못 씀): ① 목표 칸의 물체·상태 "들고 있음"(늘 넣음) ② 로봇과 같은 방(물체의 방 id) ③ 로봇에서 가까운 순(로봇 기준 xyz 차이의 길이) ④ 최근 본 순(마지막 본 뒤 시간) — 위에서부터 비교. 모두 물체 칸에 이미 있는 값. 학습된 판단(검색 질의 어텐션)은 그 뒤 정밀 칸 8 고르기에서 쓴다. GPU 지도는 꽉 차면 지금처럼 새 후보를 버리지 않고 이 순서의 맨 뒤(멀고 오래 안 본 것)를 버린다. 몸통 입력은 물체 수와 무관하게 기억 토큰 32 + 정밀 칸 8.

순서: ① GPU 지도 → 관측에 기억 전체(압축) 넘기기(map_tok·obs, 위 상한·고르기 규칙) ② 교사 망에 요약 인코더 앞·뒤 계산(CPU 참조판 + GPU, `training/RL/network`) ③ 검증(ppo_verify v4–v7 를 새 구조로, 바퀴당 시간 비교) ④ 교사 다시 학습. 학생 쪽 2.8 구현(`training/vla VCfg::mem`)과 수식·초기화를 맞춘다.

## 1단계(지도 최대한 많이 쌓기) — 만들 것
- GPU 환경(`training/RL/env`)에 탐사 판을 더한다: 목표 칸 없음, 보상 = 스텝마다 **새로 본 칸 수**(GPU 지도가 방마다 이미 셈 — `map.h count_new_seen`), 충돌 벌 그대로, 판 끝 = 정해진 시간.
- 점수 = 그 시간 안 덮은 비율(방 안 칸 기준). 성공 판정은 덮은 비율 문턱(정할 것).
- 고친 뒤 `env_verify`(다른 단계 비트 동일)로 확인.
