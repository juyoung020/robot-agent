# BC — 모방학습 (VLA 증류)

RL 전문가가 시뮬에서 성공한 궤적(영상, state, 지도 토큰, 행동)과 자연어 단계 지시로 Qwen 기반 VLA를 학습한다. 몸통(Qwen3.5-2B + 자체 비전 타워)은 얼리고 flow matching 액션 전문가와 지도 토큰 인코더를 학습한다. C++/CUDA/Rust 네이티브만 쓴다(PyTorch·JAX 등 프레임워크와 Python 학습·추론 코드 금지. 층별 정확성 검증용 오프라인 기준값 덤프만 예외).

## G5 — 작은 학생 BC 학습기(BF16)·자료 경로·DAgger (계획서 GPU_TRAINING.md 4.5·4.6·5.3·5.4·9·11절)

이번 판은 **student-lite** 다: 영상 없이 몸 상태 + 지도 토큰(+ 지시 번호)만 보는 학생으로 기록 → BC → DAgger → 폐루프 평가의 배관을 전부 GPU 안에서 증명한다.
**영상(RGB 2 장 → SigLIP 2 패치 토큰)은 아직 학생 입력에 없다(남은 일 1).** 영상 경로를 고르기 위한 224² 렌더 속도는 쟀다(아래 "렌더").

### 구성
| 경로 | 언어 | 내용 |
|---|---|---|
| `include/bc_data.h` | C++/CUDA 공용 | 자료 형식(5.3), 학생 입력 `assemble_student`, 렌더 상태 `RenderState` — CPU·GPU 같은 소스 |
| `src/bc.cu`, `include/bc.h` | C++/CUDA | 롤아웃 그래프(교사 앞 → 학생 앞 → 행동 고르기·기록 → G1 환경 → 에피소드 표 → G2 지도), 갱신 그래프(K × [모으기 → 앞 → MSE → 뒤 → Adam]), 기록 링, C ABI |
| `include/bc_capi.h` | C | Rust 가 쓰는 ABI |
| `tools/bc_verify.cu` | C++/CUDA | V5(CPU FP64·EMUL 참조판 + 유한 차분 + 음성 대조), 기록 = 본 것, V6, V7, 처리량 |
| `tools/render_bench.cu` | C++/CUDA | 팀 `RenderBatch`(읽기만, include) 로 A2 장면을 224² 두 카메라로 그리는 속도 |
| `driver/` | Rust | 설정(JSON), 실행 순서(교사 평가 → 교사 기록 → BC → 평가 → DAgger i [학생 롤아웃·교사 라벨 → 갱신 → 평가]), CSV·결과 JSON |
| `config/` | JSON | 실행 설정 |

`../RL` 의 G1 환경·G2 지도·관측·신경망 커널(손 BF16 GEMM, 칸 MLP 묶음, dW 조각 합, Adam)·CPU 참조판은 **소스를 읽기만** 해서 같이 빌드한다(바꾼 것 없음).

### 교사
A2 토큰 켬 씨앗 1(`~/ra_ppoout/g5/t4/on_s1/ckpt_final.bin`, `../RL/ppo/README.md` "A2 학습": 결정적 0.946·충돌 0.032, 빈 지도 0.948). 정책 사슬 A1–A4 + 칸 MLP 만 앞 계산한다(bf16 사본, 가치 사슬 안 씀).
라벨 = 교사 결정적 행동 clamp(μ, ±1) (vx, wz). 나머지 행동 6 개는 이 단계(approach)에서 0 고정(CURRICULUM 3절, 교사와 같음).

### 학생(student-lite)과 교사의 정보 차이(5.4)
| 입력 | 교사 | 학생 |
|---|---|---|
| 몸 상태 53 + 벽 광선 16(G1 관측) | 그대로 | 그대로 |
| 목표 칸(G1 관측 53–55 손끝 → 목표, 72–79 목표 xy·거리·방위·보임·겉면·카메라 거리·표시) | 지도에 컵이 확정되면 **참값**(잡음·slam 오차 없음 = 5.4 교사 특권) | **늘 0** |
| 지도 토큰(물체 칸 16 × 48, 벽 56, 방 10, 완성도 4, 안 본 곳 광선 8) | 그대로(`use_map` 2) | 그대로 — 목표는 지도의 목표 칸(잡음·slam 오차가 든 위치, `T_TARGET`)으로만 앎 |
| 지시 문장 | — | A2 과제가 "컵으로 가" 하나라 번호가 늘 같아 편향 칸과 같다 → 넣지 않음 **(가정)** |
| 영상 RGB 2 장 | — | **아직 없음(TODO)** |

- 신경망은 교사의 정책 사슬과 같은 모양(칸 MLP 48→64→64, 집합 128, A1 288→256 → 256 → 128 → 8)이다. 학습 변수 187,520 개. 학생은 무작위 초기화(교사 가중치를 쓰지 않음).
- 손실: MSE `(1/M) Σ_r Σ_{k<2} (μ − 라벨)²`. 계획서의 flow matching 액션 전문가·행동 청크(VLA_INPUT 5절)는 아직 아니다 — 한 스텝 결정적 회귀로 배관부터 **(가정, 남은 일 2)**.
- `student_goal: 1` 이면 학생이 교사와 같은 입력을 본다(정보 차이 없이 모방 오차만 남기는 대조).

### 자료(5.3) — 스텝마다 정책이 실제로 본 것
| 칸 | 크기 | 내용 |
|---|---|---|
| obs | 80 × bf16 = 160 B | bf16(clamp10(G1 관측)). 정책 입력이 이 값을 그대로 bf16 로 쓰므로 무손실 |
| tok | 1,280 B | 그 스텝 지도 토큰 `MapTok` 그대로(물체 칸 16 × 33 FP16, 이름·생김새 번호, 벽 56, 방, 완성도, 안 본 곳 광선) |
| lab | 2 × f32 | 교사 라벨 |
| meta | u32 | 에피소드 스텝, 처음 지도 부호, 움직인 쪽(교사/학생) |
| rs | 144 B | 렌더 상태: 지도 토큰과 같은 순간의 몸 자세·팔 6 각·컵·방 반치수·가구 8 상자(FP16)·종류 → 학습 때 다시 렌더 |
| 합 | **1,596 B/표본** | (계획서 추정 1.3 KB) |

- 장치 안 고리 버퍼(`cap` 표본, 넘치면 오래된 것부터 덮어씀). 쓰기 자리·표본 수는 장치 값(`Data`)이고 롤아웃 그래프 끝 커널이 옮긴다. 미니배치는 장치 열쇠(씨앗, 갱신 스텝, 행) 해시로 균등 복원 추출.
- 롤아웃이 교사 앞 계산(라벨)을 **같은 그래프 안에서** 늘 한다. 누가 움직이나(교사/학생)·기록하나는 장치 값 `Mode`(고정 호스트 링 → 비동기 복사)라 그래프를 다시 잡지 않는다 → 교사 기록, DAgger(학생이 움직이고 교사가 라벨), 평가가 한 그래프.
- 렌더 상태는 지도 토큰과 같은 순간(환경 스텝 뒤 = 리셋된 판은 새 판)이다. G1 관측은 "끝난 스텝" 값을 돌려주므로 리셋 직후 첫 스텝만 관측(이전 판 끝)과 토큰·렌더 상태(새 판)가 어긋난다 — 교사 PPO 와 같은 알려진 어긋남(`../RL/ppo/README.md`).

### 처리량 — 잰 값(GPU 다른 일 없음, `bc_verify bench`, N 4,096, T 64)
| 잰 것 | 값 |
|---|---|
| 롤아웃(교사가 움직이며 기록, 교사·학생 앞 둘 다) | **50.1 ms / 262,144 스텝 = 5.2e6 env-step/s** (그래프 노드 1,217) |
| 롤아웃(학생이 움직임, 기록 없음 — 평가) | 38.1 ms (6.9e6 env-step/s). 기록(1,596 B × 262,144 = 418 MB 쓰기)이 약 12 ms |
| 갱신(미니배치 8,192, 50 스텝 한 그래프, 노드 1,051) | 23.6 ms = **0.47 ms/스텝, 1.73e7 표본/s** |
| 갱신(미니배치 16,384) | 0.84 ms/스텝, 1.95e7 표본/s |
| 장치 메모리 | 자료 버퍼 cap 3.5M 표본에서 5.94 GB(그중 자료 5.59 GB), cap 0.5M 이면 1.19 GB |
| 본 실험 한 판(아래 표 한 열: 교사 평가 + 기록 + BC 6,000 스텝 + DAgger 8 × (롤아웃 + 2,000 스텝) + 평가 10 번) | 벽시계 63 s(다섯 판 모두), 그중 GPU: 갱신 약 22 s, 평가 10 번 약 40 s |

**호스트 동기**(nsys, `bc_run` 그대로, 기록 4 + BC 40 + 평가 + DAgger 2 + 20 + 평가): 단계 안에서는 `cudaGraphLaunch`·`cudaEventRecord`·`cudaEventQuery`(기다리지 않음)뿐이다 —
기록 4 + BC 갱신 40 = 그래프 44 개, DAgger 롤아웃 2 + 갱신 20 = 22 개를 동기 없이 연달아 띄움. 평가는 모드 복사(`cudaMemcpyAsync`) → 3 → 표 지우기(`cudaMemsetAsync`) → 3.
`cudaDeviceSynchronize`·`cudaMemcpy` 는 단계 경계(환경 다시 만들기·그래프 다시 잡기, 표 읽기, 학생 저장)에만 있다.

### 폐루프 평가 — BC 대 DAgger (잰 값)
설정 `config/bc_a2.json`: 교사 기록 4 롤아웃(1,048,576 표본, 교사가 움직임) → BC 6,000 스텝(미니배치 8,192, Adam 3e-4 고정) → DAgger 8 번 [학생이 움직이고 교사가 같은 상태에 라벨, 1 롤아웃 = 262,144 표본 더함 → 모은 자료 전체에서 2,000 스텝] (모두 **가정** 값).
대조 "교사 자료 더": 같은 일정에서 DAgger 롤아웃 대신 교사가 움직이며 기록(자료 양·학습 양이 같음). 자료와 평가 모두 처음 지도 C0 20 %·C1 60 %(미리 확정 1–8 개)·C2 20 %.
평가: 결정적 정책, A2, 4,096 판 × 40 롤아웃(앞 3 버림 = `ppo_verify eval` 과 같은 규칙), 평가 환경 씨앗 고정(모든 평가가 같은 장면 차례). 교사도 같은 틀로 잼.

성공 / 충돌 (전체, 처음 지도 C0 · C1 · C2 별). 에피소드 약 106–108k 개씩 → 성공률 표준오차 약 0.0007.

- **DAgger 8 번이면 교사와 같다**(0.9455·0.9464 대 0.9459, 차이가 표준오차 안). 같은 양의 교사 자료를 더 준 대조는 0.9444·0.9431 로, 두 씨앗 모두 DAgger 가 0.001–0.003 높다(표준오차 2–4 배 — 씨앗 둘이라 작은 차이로 본다). 차이가 작은 까닭은 BC 가 이미 교사 가까이 있어 학생이 교사 궤적 밖으로 크게 벗어나지 않기 때문이다(추정). 학생이 간 자리에서 교사와 어긋남(MSE)은 0.0028 → 0.0008 로 줄었다(씨앗 1, DAgger 1 → 8).
- **특권 목표의 값**: 학생에게 교사와 같은 목표 칸을 주면 BC 가 0.9332 → 0.9395 로 오른다 — 정보 차이가 BC 차이(0.013)의 약 절반. DAgger 8 뒤에는 둘 다 교사 수준(0.9455 대 0.9466)이라, 지도 토큰의 목표 칸(잡음·slam 오차 있음)만으로도 교사 행동을 거의 다 따라 한다.
- 완성도 칸별(씨앗 1, 성공 / 충돌): 0 % 교사 0.946/0.017 · BC 0.927/0.022 · DAgger 8 0.946/0.017, 0–30 % 0.936 · 0.921 · 0.935, 30–70 % 0.939 · 0.931 · 0.941, 70–100 % 0.954 · 0.941 · 0.951, 100 % 0.957 · 0.946 · 0.957.

### 한계·가정
- **영상 없음(student-lite)**: VLA_INPUT 의 카메라 2 장·SigLIP 2 패치 토큰·지시 문장 토큰이 학생에 없다. 그래서 "작은 VLA" 가 아니라 교사와 같은 모양의 MLP 학생이고, 결과는 BC·DAgger 배관과 정보 차이(특권 목표) 효과까지만 말한다.
- 손실은 한 스텝 MSE(결정적). flow matching·행동 청크 아님. 이름·생김새는 교사처럼 원-핫(SigLIP 표 없음).
- 하이퍼파라미터(학습률 3e-4 고정, 미니배치 8,192, 스텝 수, DAgger 일정, β = 0 — DAgger 롤아웃은 늘 학생이 움직임)는 **(가정)**. 씨앗 둘(학생 초기화·자료 씨앗).
- 교사 라벨은 교사 결정적 평균(clamp ±1). 교사 정책이 놓친 판(충돌 3 %)도 그대로 따라 배운다 — 성공한 궤적만 고르지 않았다(5.4 DAgger 는 모든 상태에 라벨).
- 평가 장면은 학습 장면과 같은 생성기(A2)·다른 씨앗이다. VLA_INPUT 7절의 안 본 이름·안 본 집 평가는 아직(장면 생성기가 하나).
