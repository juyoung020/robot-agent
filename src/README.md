# src

코드를 둔다. ROS 2 패키지는 이 폴더 안에 만든다 (레포 루트에서 `colcon build`).

| 폴더 | 역할 |
|---|---|
| `scene_graph/` | 동적 3D scene graph: 로봇이 본 물체를 3D 지도에 등록·갱신 (로봇의 기억) |
| `agent/` | 그래프를 이용한 장기 계획, 단계 추적, 실패 복구 |
| `vla/` | VLA(π0.5): 현재 단계 지시 + 카메라 영상 → 행동 |
| `app/` | 휴대폰 앱 (iOS·Android 네이티브). 카카오톡식 채팅으로 로봇에게 명령, 지금은 로봇1 만 |
